# SlowDown (Слоу Даун)

Сервис для совместного выращивания онлайн-питомца Серунчика!

## Описание

SlowDown - это веб-приложение, где вы можете создать питомца Серунчика и выращивать его вместе с друзьями (от 1 до 3 человек).

### Особенности:
- **Командная игра**: Пригласите друзей для совместного выращивания
- **3 характеристики**: Сытость, Энергия, Настроение
- **Эволюция**: Яйцо → Малыш → Подросток → Взрослый
- **Ежедневные миссии**: Выполняйте задания для быстрого роста
- **История действий**: Видите, кто и что сделал

## Запуск локально

```bash
cd slowdown
pip install -r requirements.txt
python main.py
```

Приложение будет доступно по адресу: http://localhost:8000

## Деплой на Railway

1. Создайте новый проект на [Railway](https://railway.app/)
2. Подключите ваш Git репозиторий
3. Добавьте volume для хранения базы данных:
   - Название: `slowdown-data`
   - Mount path: `/workspace/slowdown`
4. Приложение автоматически запустится

## Игровой процесс

1. **Регистрация**: Создайте аккаунт с логином и паролем
2. **Создание питомца**: Нажмите "Создать Серунчика"
3. **Приглашение друзей**: Пригласите 1-3 друзей по логину
4. **Уход за питомцем**:
   - 🍖 Кормить (+сытость, +прогресс)
   - 🎾 Играть (+настроение, +прогресс)
   - 💤 Отдых (+энергия, +прогресс)
5. **Выполнение миссий**: Дневные задания дают бонусы к прогрессу
6. **Эволюция**: При 100% прогресса питомец эволюционирует
